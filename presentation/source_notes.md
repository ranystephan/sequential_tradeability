# Presentation Source Notes

The deck is built from project-owned source material only.

- Mathematical formulas are rendered from `presentation/render_formula_assets.py`.
- The main deck is generated by `presentation/build_deck.mjs`.
- Empirical figures are pulled from the project `figures/` directory.
- The speaker script is in `presentation/speaker_script.md`.
- Optional animation planning is in `presentation/manim_scenes.md`.

No external stock imagery or untracked web assets are used.
